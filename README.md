# Telegram-бот для агентства недвижимости

Бот принимает заявки на создание продающих видеороликов: клиент отправляет ссылку на объявление, фото и текст. Данные сохраняются в БД, администратор обрабатывает заявки через веб-панель или команды в Telegram.

## Возможности

**Для клиента:**
- Приветственный текст до нажатия /start (описание бота)
- Создание заявки: ссылка + фото + комментарий
- Просмотр своих заявок и их статусов

**Для администратора (как на скриншоте):**
- **Группа с топиками** — каждый клиент = отдельный топик `🔵 Имя ID 123456789`
- Видно всё в реальном времени: /start, ссылки, фото, сообщения
- **Ответ в топике** → клиент получает сообщение в боте
- Дополнительно: веб-админка и команды `/admin`, `/orders`, `/status`

## Быстрый старт

### 1. Создайте бота и группу

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → токен
2. `/setdescription` — текст приветствия из `config.py`
3. **Создайте супергруппу** (например «Клиенты | Видеоролики»)
4. **Включите «Темы»** в настройках группы
5. **Добавьте бота админом** с правом «Управление топиками»
6. Добавьте [@RawDataBot](https://t.me/RawDataBot) в группу → скопируйте `chat.id` → это `ADMIN_GROUP_ID`

### 2. Настройте окружение

```bash
cp .env.example .env
# Отредактируйте .env:
# BOT_TOKEN=...
# ADMIN_IDS=ваш_telegram_id  (узнать: @userinfobot)
# ADMIN_GROUP_ID=-1001234567890  (ID группы с топиками)
# ADMIN_PASSWORD=надёжный_пароль
```

### 3. Установите зависимости

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4. Запуск

```bash
# Бот + веб-админка вместе
python run.py

# Или по отдельности:
python run.py bot   # только Telegram-бот
python run.py web   # только админка на http://localhost:8080
```

## Статусы заявок

| Статус | Описание |
|--------|----------|
| `new` | Новая заявка |
| `in_progress` | В работе |
| `completed` | Готово |
| `cancelled` | Отменена |

При смене статуса клиент автоматически получает уведомление в Telegram.

## Админ-команды в Telegram

| Команда | Описание |
|---------|----------|
| `/admin` | Сводка |
| `/orders` | Новые заявки |
| `/order 5` | Детали заявки #5 (+ фото) |
| `/status 5 in_progress` | Сменить статус |
| `/reply 123456789 Текст` | Написать клиенту |

## Схема работы (админка в Telegram)

```
Клиент пишет боту (/start, ссылка, фото...)
         ↓
  Топик в группе: 🔵 Алена ID 1000574068
         ↓
  Админ видит всё в списке топиков и отвечает прямо там
         ↓
  Клиент получает ответ в боте
```

Проверка настройки группы: `/setup` (от админа).

## Веб-админка

Откройте `http://localhost:8080`, войдите с логином/паролем из `.env`.

- Дашборд со статистикой
- Фильтр по статусам
- Карточка заявки: данные клиента, ссылка, комментарий
- Форма смены статуса и отправки сообщения

## Деплой на Railway (через GitHub)

Репозиторий: https://github.com/Devmakicy/real-estate-telegram-bot

1. Откройте [Railway](https://railway.com/) → **Login with GitHub**
2. **New Project** → **Deploy from GitHub repo**
3. Выберите `Devmakicy/real-estate-telegram-bot`
4. В **Variables** добавьте:
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `ADMIN_GROUP_ID`
   - `BOT_DISPLAY_NAME`
   - `SECRET_KEY`
   - `ADMIN_USERNAME`, `ADMIN_PASSWORD` (для веб-админки)
5. **Settings → Deploy** → Start Command: `python run.py bot`
6. (Рекомендуется) **Add Volume** → mount `/app/data` для сохранения SQLite

Для веб-админки создайте **второй сервис** из того же репо:
- Start Command: `python run.py web`
- Включите **Public Networking** → получите URL
